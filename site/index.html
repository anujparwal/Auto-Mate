Start locally

A public website. A private owner window.

This download page never connects to your vault. The working app runs on your Windows PC; it does not expose a local HTTP vault server.

  1. Extract the package

    Download the ZIP, verify its SHA-256 checksum, and extract it into a folder you control. Review the source and setup script before running them.

  2. Install the prerequisites

    Open PowerShell in the extracted folder. Run the setup script, then reopen PowerShell if Bun was installed.

    powershell.exe -NoProfile -File .\tools\setup-windows.ps1

    If Windows blocks the script, inspect it and follow the usage guide; do not weaken machine-wide security settings.

  3. Open your owner window

    bun start

    The app opens its browser window automatically. Start with Public login test → Inspect website. Inspection does not access the vault; no fields are preapproved.

Trust boundaries

Approval is not delegated to AI.

  • Native DPAPI encrypts records on your PC. Normal save/list/read operations require Windows Hello.
  • The receiving website can read anything filled into its fields. Stop cannot undo an earlier disclosure.
  • The app does not click Login, Pay, or Submit in real-site autofill.
  • No vault values, ciphertext exports, owner previews, or approval controls are model tools.
  • Embedded payment frames, SSO, CAPTCHA, MFA, and arbitrary cross-origin navigation are not bypassed.
